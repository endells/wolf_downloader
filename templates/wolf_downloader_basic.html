처리 대상과 검사 방식

등록된 작품의 이름만 있는 폴더에는 [작품번호]를 붙입니다. 목록 밖의 작품과 다른 번호 없는 폴더는 무시합니다. 같은 이름의 대상 폴더가 있으면 합치지 않고 중지합니다.

ZIP은 압축을 풀지 않고 내부 이미지 목록으로 페이지 수를 계산합니다. 변경 없는 ZIP은 캐시를 재사용하고, 내용이 같을 가능성이 있는 중복 ZIP만 추가 비교합니다.

작품 목록 조회는 수행하지만 ZIP마다 회차 웹페이지를 조회하지는 않습니다. ZIP 전체 손상 검사와 사이트 원본의 페이지 수 대조는 생략하며, 이미지 회차 폴더는 사이트와 대조합니다. 원본 플러그인의 DB는 변경하지 않습니다.

파일 이름과 보관 파일 정리

0바이트·ZIP 목록 오류 파일은 회차를 확인해 다시 받습니다. 앞번호와 제목의 화수가 충돌하면 복구를 보류합니다. 새 ZIP 검증 후 문제 파일을 교체하며, 실패 시 기존 파일을 유지합니다.

파일명은 앞번호_제목 #이미지수.zip 형식으로 맞춥니다. 같은 앞번호·동일 이미지의 중복 ZIP은 .duplicates에 보관합니다.

.duplicates, [보존-N] 및 이력 반영에서 따로 보관한 ZIP은 설정한 유지 기간이 지나면 내용이 달라도 삭제합니다. 기존 보관 파일은 처음 확인한 시점부터 계산합니다.

이력에서 사용하는 원본과 마지막 남은 파일은 유지합니다. 빈 .duplicates 폴더만 삭제하고 작품·상위 공유 폴더는 유지합니다.

완료 폴더 ZIP 변환 안내

이 플러그인이 만든 완료 회차 폴더만 ZIP으로 변환합니다. ZIP 검증이 끝나면 해당 원본 회차 폴더를 삭제합니다.
